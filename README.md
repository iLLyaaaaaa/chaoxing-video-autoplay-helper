# 学习通视频连续播放助手

Tampermonkey 用户脚本，当前版本为 **v22.4**。脚本仅匹配 `https://*.chaoxing.com/*`。

## 功能

- 自动静音并尝试播放课程视频。
- 鼠标移出页面时拦截可能触发暂停的事件，并尝试保持后台播放。
- 视频结束时优先采用浏览器的 `video.ended` 状态，并以接近总时长的播放进度作为兜底；确认结束后按三级课程目录顺序尝试进入下一课。
- 检测到视频中的判断题弹窗时，发出两声提示音并闪烁标签页标题；返回标签页后停止闪烁。
- 判断题出现期间暂停自动恢复播放；题目消失约 700 ms 后，重新静音并尝试恢复当前视频。
- 判断题的选择和提交由用户手动完成。

## 安装

1. 在浏览器中安装 Tampermonkey。
2. 打开 [`chaoxing-video-autoplay-helper.user.js`](./chaoxing-video-autoplay-helper.user.js)，复制全部内容到 Tampermonkey 的新脚本编辑器并保存。
3. 只启用这一份脚本，打开或刷新学习通课程页面。

## 使用说明

脚本会在匹配的学习通页面及其匹配的 iframe 中运行。浏览器的自动播放和音频策略可能要求先与页面交互；课程页面结构变化也可能影响自动播放、目录识别或判断题提醒。请以页面上的实际播放和学习进度为准。
